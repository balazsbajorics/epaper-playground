How the code runs

Your code is the body of function draw(ctx, width, height, t). ctx is a normal 2D context of a canvas the size of the panel; t is milliseconds since the first run. Draw in any colour: the result is converted to 1-bit with the dither and threshold above, then submitted to the panel as a partial refresh (or full with the second button). Partial refreshes only move the pixels that changed and leave ghosts; after fullEvery partials the panel cleans itself. See the README for the API.
